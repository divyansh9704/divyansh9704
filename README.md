## 🚀 Featured Engineering Projects

### [Engineering Intelligence Platform](https://github.com/divyansh9704/engineering-intelligence-platform)
> **Automated PR Blast Radius & AST Code Graph Analysis Platform**
* **The Problem:** Developers make PRs without fully understanding the cascading downstream effects on distributed architectures, leading to regressions and blind spots.
* **What I Built:** A production-grade multi-hop architecture mapping tool that analyzes code blast radius using Abstract Syntax Trees (Tree-sitter) and vector embeddings (pgvector).
* **Engineering:** Built with FastAPI, Next.js, and PostgreSQL. Features recursive CTEs for graph traversal, hybrid RAG (semantic + AST), automated PR impact scoring, and strict hard-tenant data isolation.

### [Med-secure](https://github.com/divyansh9704/Med-secure)
> **Steganography-Based Secure Medical Communication Platform**
* **The Problem:** Medical data transmission requires absolute privacy against unauthorized interception.
* **What I Built:** A dual-layer secure messaging system where sensitive health data is encrypted via Fernet, then concealed inside PNG/WAV files using LSB steganography before transmission.
* **Engineering:** JWT-based RBAC authentication, robust Express/MongoDB backend, and a modern React client.

### [Nexa](https://drive.google.com/file/d/19bnVl2_fzerzsZqoiiPKd4p9Ats7w0oj/view?usp=sharing) *(Private / View Architecture Doc)*
> **AI-Powered Privacy-First Conversational Search Assistant**
* **The Problem:** Commercial AI search tools compromise user data and often hallucinate without grounding.
* **What I Built:** A local, privacy-first conversational search engine utilizing a 4-tier RAG architecture.
* **Engineering:** Integrated Ollama with SearXNG for web grounding, utilized Server-Sent Events (SSE) for real-time token streaming, and engineered dynamic widgets for live data (stocks/weather/math) on a Next.js/SQLite stack.

### [NexMedFL](https://drive.google.com/file/d/1dG54KZxob0CVdNGUuOcLXCmeQ_ayfsHc/view?usp=sharing) *(Private / View Architecture Doc)*
> **Privacy-Preserving Federated Learning Framework**
* **The Problem:** Training predictive medical AI models usually requires centralizing highly sensitive patient data.
* **What I Built:** A decentralized framework that trains disease prediction models across distributed nodes without sharing raw data.
* **Engineering:** Built with PyTorch and Flower. Applied differential privacy via Opacus (Gaussian noise, gradient clipping) and optimized communication using INT8 quantization and gRPC.

### [CropSense](https://github.com/divyansh9704/CropSense)
> **IoT & ML-Driven Agricultural Microservices Platform**
* **What I Built:** A massive IoT and market-analysis backend for agricultural management.
* **Engineering:** Engineered a multi-service architecture using NestJS, PostgreSQL (TimescaleDB), Redis, and EMQX (MQTT). Features BentoML integration and production-ready Kubernetes/Helm deployment charts.

### [Praxis](https://github.com/divyansh9704/Praxis)
> **Native Desktop AI Assistant**
* **What I Built:** A high-performance native desktop application serving as a unified AI workflow assistant.
* **Engineering:** Written in Rust and Tauri with a Vite/React frontend. Designed for maximum memory efficiency, leveraging OpenRouter APIs and local OS keychains.

### [healthos](https://github.com/divyansh9704/healthos)
> **AI-Powered Budget-Conscious Meal Planning Ecosystem**
* **What I Built:** A platform that generates highly accurate, budget-constrained nutritional meal plans.
* **Engineering:** Built a strict-schema AI parser using FastAPI and OpenRouter, paired with a Next.js frontend and containerized via Docker.
